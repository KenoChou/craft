# 水电安装服务与工程交易平台

> 项目文档与架构决策仓库。用于沉淀商业定位、法律与资金边界、产品规则、数据模型、技术方案及实施决策。

## 项目目标

建设面向中国大陆市场的水电安装产业交易平台，连接业主、施工人员、施工企业、工程承包商及材料供应商，覆盖住宅服务交易与商业工程项目交易。

平台不是单纯的信息黄页或招聘工具。产品目标是逐步形成需求发布、报价撮合、合同协作、施工履约、验收、支付协作、售后评价的交易闭环。

## 当前规划原则

1. **先验证真实交易，再扩大技术规模。** 首期以单城市、有限服务品类验证供需密度和交易闭环。
2. **住宅服务与商业工程分开建模。** 两者可共享身份、组织、合同、文件、支付协作等基础能力，但不能共用一套过度简化的订单规则。
3. **区分平台撮合与平台自营。** 默认按第三方交易市场设计；自营业务必须单独识别签约主体、履约责任、资质及税务关系。
4. **资金合规优先。** 平台业务账本不等于资金账户；支付、收单、分账和结算必须由具备相应资质的合作机构按其产品规则提供。接入支付机构不自动消除平台自身的合规责任。
5. **决策可追溯。** 每项重要设计记录状态：已确认、建议、待验证或待专业机构确认。未经确认的假设不得写成既定事实。
6. **渐进式架构。** MVP优先采用边界清晰的模块化架构，按真实负载演进，不为长期DAU目标提前引入不必要的分布式复杂度。

## 实施阶段

### 阶段 0：商业验证与合规核验
- 选择首发城市和首批服务品类。
- 访谈业主、施工人员、施工企业及潜在工程客户。
- 验证供需密度、报价习惯、履约痛点和服务费接受度。
- 与律师、税务顾问及银行/持牌支付机构核验经营主体、合同、发票和资金路径。

### 阶段 1：单城市住宅服务 MVP
- 需求发布与审核
- 服务商准入与资料核验
- 报价、选择与合同协作
- 施工记录、变更、验收和售后
- 合规支付机构接入与交易对账
- 平台运营、投诉和审计后台

### 阶段 2：城市网络与企业能力
- 多区域服务能力
- 企业组织与成员权限
- 派单、排期、服务质量与经营分析
- 企业会员及项目协作能力

### 阶段 3：商业工程与供应链
- 工程项目发布、承包商准入和专业包
- 工程合同、变更签证、节点验收及结算
- 材料目录、供应商撮合与采购协作

### 阶段 4：跨城市复制与专业扩展
在城市供需、履约质量、单位经济和合规能力经过验证后，逐步扩展城市与暖通、消防、弱电、机电等专业。

## 决策状态约定

- **已确认**：项目决策人明确批准，可作为后续设计依据。
- **建议**：当前推荐方案，尚未获得明确批准。
- **待验证**：需要用户访谈、真实交易数据或市场实验验证。
- **待专业确认**：需要律师、税务顾问、监管部门或持牌合作机构确认。
